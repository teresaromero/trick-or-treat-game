About Trick or Treat

Trick or Treat is a small Halloween game: catch the falling pumpkins, dodge the fakes and don't let the pumpkins reach the bottom.

The story

It was my first coding project, built in 2018 for a coding bootcamp in Madrid. In 2020 I refactored it as version 2.0, and in 2026 I gave it a new look, levels and this site as version 3.0.

It is plain HTML, CSS and JavaScript on a canvas: no framework and no build step. The code is open on GitHub.

Accessibility

Catching items needs a mouse or touch: the board can't be played with the keyboard yet. Pause and quit work from the keyboard. See How to play for details.
